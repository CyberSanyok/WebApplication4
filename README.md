# WebApplication4
Проект попрактиковаться на ASP.NET Core 6 MVC + EF Core + Identity + Leaflet.js.

Функции:
- Регистрация и вход пользователей
- Общая доска сообщений с пагинацией и поиском
- Интерактивная карта с цветными метками
- Комментарии к меткам
- Аватарки 

Технологии:
ASP.NET Core 6, Entity Framework Core, SQLite, ASP.NET Identity, Bootstrap 5, Leaflet.js, Leaflet.markercluster
